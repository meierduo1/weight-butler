# 统计模型

这个项目不是“体重记录器 + 折线图”。它试图回答一个更窄的问题：

> 在每天只有一次体重、饮食记录还不一定完整的情况下，**哪些变化值得相信？**

下面按模块说明。代码在 `app/server.js`，每个函数上方都有中文注释。

---

## 1. 去噪体重：Holt 双参数指数平滑

每日体重 = 真实水平 + 水分/糖原/肠道内容物噪声。直接看单日会疯。

Holt 把序列拆成「水平」和「趋势」：

```
预测值_t   = L_{t-1} + T_{t-1} × gap
L_t       = α × y_t + (1-α) × (L_{t-1} + T_{t-1} × gap)
T_t       = β × (L_t - L_{t-1}) / gap + (1-β) × T_{t-1}
```

- `gap` 是两次记录之间的真实天数。断记几天时按 gap 缩放，不会把 7 天的变化摊到 1 天。
- α、β 通过网格搜索最小化一步预测误差。
- 输出：**去噪体重**（卡片大数字）和**近期速度**（斤/周）。

Holt 不滞后于转向，适合“最近是不是变快了/变慢了”这个问题。

---

## 2. 长期速度：最小二乘 + 95% 置信区间

对 `(day, weight)` 做 OLS：

```
slope = Σ(x-x̄)(y-ȳ) / Σ(x-x̄)²
```

输出速度（斤/周）和 95% CI。区间不跨 0，才叫“确实在下降”。

但普通 OLS 在这里会**过度自信**，原因见下一节。

---

## 3. 关键修正：AR(1) 自相关

体重有惯性：今天偏高，明天也倾向偏高。残差不是独立的。

朴素 OLS 的 95% 区间覆盖率实测只有约 **78%**，不是 95%。项目用 AR(1) 修正：

```
ρ = lag-1 残差自相关（小样本偏差校正，下限 0.5、上限 0.8）
膨胀因子 = sqrt( x' V x / x'x )，V_ij = ρ^|i-j|
SE_AR = SE_naive × 膨胀因子
```

修正后区间变宽，但覆盖率接近名义水平。界面上展示的永远是修正后的区间，并同时列出“未修正会是多少”，方便看出差别。

ρ 取 0.5 下限是保守选择：小样本里 ρ 的估计偏差很大，只信估计值会继续过度自信。

---

## 4. 稳健性：Theil–Sen

所有点两两配对求斜率，取中位数：

```
slope = median{ (y_j - y_i) / (x_j - x_i) }
```

对异常值不敏感，用来和 OLS 互相验证。不给区间。

---

## 5. 变化门槛：多少才算真变化？

用残差标准差估计测量噪声 σ，再用同一个 AR(1) 膨胀因子修正均值标准误：

```
SE_mean = σ × 膨胀因子 / sqrt(7)
minDelta = 1.96 × sqrt(2) × SE_mean
```

两个 7 日均值之差超过 `minDelta`，才认为发生了真实变化；否则默认是水。

这个数字会直接显示在页面底部，并且会同时给出“不修正自相关会误判成多少”。

---

## 6. TDEE：三种口径

TDEE（维持热量）用能量守恒反推：

```
TDEE ≈ 平均摄入 + 体重下降对应的每日缺口
缺口 = 掉掉的 kg × 7700 / 天数
```

三种口径：

1. **滚动窗口**（主）：只看最近 14 天，避免被三周前的旧数据拖着
2. **EWMA**：逐日递推，代谢适应能跟上，最灵敏
3. **配对中位**：所有 ≥10 天的窗口各算一个 TDEE，取中位数，作为交叉验证

前 3 周不给 TDEE 数值：早期掉的体重里糖原和水占大头，会把缺口算大、TDEE 高估。

---

## 7. 活动系数：从数据反算

Mifflin–St Jeor：

```
BMR = 10×kg + 6.25×cm − 5×age + (male ? +5 : −161)
```

用数据反推的 TDEE 除以 BMR，得到真实活动系数，再和公式默认区间（1.35~1.55）对比。如果实测明显偏低，说明公式假设偏乐观，不该直接拿来算热量缺口。

---

## 8. 蛋白目标：按去脂体重

```
去脂体重 = 体重 × (1 − 体脂率)
目标蛋白 = 去脂体重 × 1.6 ~ 2.0 g/kg
硬底线 = profile.protHardFloor
```

按总体重算会得出偏高的数字，因为脂肪不需要蛋白。

---

## 9. 预测：指数衰减，不是直线

每掉 1 kg，TDEE 会下降约 20~25 kcal，速度必然越来越慢。项目用一阶衰减：

```
速率(t) = r0 × exp(−t / τ)
τ = 7700 / k，k ≈ 22 kcal/kg
```

数值迭代求到达目标的天数，并给出“慢 / 中 / 快”三档预测。直线外推只作为对照，标注为“一定乐观”。

7 天预测区间用 OLS 预测区间公式：

```
ŷ ± t × σ_resid × sqrt(1 + 1/n + (x0-x̄)²/Sxx)
```

## 10. 油量误差：为什么有时应该承认测不出来

如果每天吃鸡腿，残留油量是一个固定偏移。项目把每个配对窗口反推的 TDEE 对“每日鸡腿数”做回归：

```
TDEE_window ≈ a + b × 每日鸡腿数
b 应该等于“每只鸡腿残留油的热量”
```

同时计算 **MDE（最小可检出效应）**：

```
MDE ≈ 2.802 × SE(b)
```

MDE 告诉你：这个样本量能检出的最小差异是多少。  
如果 MDE 换算成油量已经超过一只鸡腿的总热量，那么这个实验在物理上做不出来——不是算法不行，是数据里没有这个信息。

与其硬给一个看起来精确的“每只鸡腿 7.3 g 油”，不如明确说“测不出来，别试了”。

---

## 11. 数据可信度

- 第 0 天（晚上裸重）自动排除
- `排除.json` 里的日期不参与拟合
- 明细表里可手动排除 / 恢复任何一天
- 每次写 CSV 前自动备份到 `data/_备份/`，保留最近 14 份
